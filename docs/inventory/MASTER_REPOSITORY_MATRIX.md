# MASTER_REPOSITORY_MATRIX.md

Authority: Mike Zachary. Compiled 2026-09-05.
Source: the fourteen repository dossiers in this directory.

Recovery operation only. This matrix records what exists. It contains no design, archive,
cleanup or refactor recommendation, and it does not rank repositories by importance.

**Method.** Every repository was cloned and read. Every tracked file in all twelve non-empty
repositories was hashed by git blob ID and compared across repositories to establish
uniqueness. Every branch of every repository was compared file-by-file against its default
branch. No test suite was run; where a dossier reports test counts they are static counts of
`def test_` functions, not results.

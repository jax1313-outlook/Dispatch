**Four defects were found, all by Mike simply trying to use it.** None would have surfaced

1. **The launcher could not be found.** 82 files in the folder; Windows hides extensions, so

4. **Two windows closed before their message could be read.** One paused only on failure; one
   hid its prompt so a repeated keypress dismissed the next one.

All four are fixed and tested.

## The failure that took the day, and why

Every page behind the login returned HTTP 500 for seven hours. The cause:

```
ModuleNotFoundError: No module named 'dispatch.connectors'
```

Mike had **three copies of Dispatch**. The one holding port 8080 all day had an incomplete
extraction — `dispatch\connectors` was missing entirely. `/login` worked throughout because it
opens no database; every freight page failed because opening the database imports the
connector registry. Deleting the broken copies fixed it.

**The diagnosis took four wrong turns**, recorded in `DECISION_LOG.md` 2026-08-25 rather than
tidied away:

1. `DISPATCH_OPERATIONS_ROOT` pointing at a dead drive — inferred from a folder that was not
   the one running. Tested and disproved.
2. A corrupt database — which reproduces the symptom *exactly*. His database passes
   `integrity_check`; he was nearly told to rename a healthy file.
3. The D: drive dropping out — built on (1) after it had been withdrawn.
4. Three separate wrong file locations, each given as an instruction.

**`dispatch-portal.log` named the module, the file and the line, and had done since 11:20 that
morning.** Every theory above was constructed while that file sat unread. Reproducing a
symptom is not diagnosing a cause.

Two operational lessons follow, and both are worth keeping:

- **A launcher that refuses to start a second server will still leave a *broken* first server
  running.** The refusal is about the port, not about whether the running code is sound.
- **Multiple copies of Dispatch is a live hazard.** Each carries its own database. A load
  entered in one and looked for in another is silently absent, with nothing wrong from either
  copy's point of view.
